# Critical Clarification Register

**Status:** `ACTIVE CLARIFICATION INTERFACE`  
**Role:** Layer 1.5 bridge for high-impact uncertainty between Layer 1 and Layer 2.  
**Language:** Chinese canonical: `clarification-register.zh-CN.md`; this English file is the synchronized mirror.

> Open entries are not human-approved claims.  
> After human resolution, promote the result into the Decision Log and the appropriate Core, then update the Argument Map and derived artifact.

## Usage rule

The AI Agent should proactively create an entry when:

- two or more reasonable interpretations of authorial intent exist;
- a key term, concept, or translation is unconfirmed;
- strong/weak readings, scope, qualifications, or inferential relations are unclear;
- a choice may materially change the core argument structure;
- new feedback may conflict with older Core / Framework state;
- a wrong guess would cause expensive rework or long-term semantic drift.

Run a Clarification Scan before major phases, Framework Approval, formal translation, large-scale expansion, and Final Review.

## Terminology / translation special rule

For key terminology, explicitly record:

- the author's primary-language expression;
- candidate English expressions;
- semantic differences among translations;
- differences in strength, disciplinary convention, or risk of misleading interpretation;
- the human-confirmed correspondence.

After confirmation:

- conceptual meaning goes to Content Core;
- primarily presentational translation convention goes to Form Core;
- durable project decisions go to Decision Log;
- Argument Map and artifact are synchronized.

## Completion condition

A clarification closes only after all are complete:

- [ ] human explicitly confirmed / corrected / deferred / rejected;
- [ ] Register records the result;
- [ ] Decision Log records the durable decision;
- [ ] relevant Core is updated;
- [ ] Argument Map is synchronized;
- [ ] derived artifact is synchronized or explicitly marked pending;
- [ ] Chinese / English mirror parity is complete.
