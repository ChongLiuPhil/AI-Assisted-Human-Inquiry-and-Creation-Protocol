# Decision Log

人类实质性决定的时间顺序审计轨迹。  
**语言：** 中文 canonical；英文 `DECISION_LOG.md` 是同步 mirror。

## 条目 schema

### YYYY-MM-DD — Dxxx

**来源：** Human author / Human acceptance of AI proposal  
**分类：** `CONTENT` / `FORM` / `PROTOCOL` / multi-label  
**决定：** ...  
**受影响文件/层：** ...  
**取代：** ... / none  
**实现状态：** pending / partial / implemented

---

## 规则

- 保留被取代的决定，不删除历史。
- 不记录每一句随意聊天；只记录持久、与项目有关的状态。
- 如果决定改变当前真值源，立即校准相关 Core。
- 显式记录 Framework Approval 与 Final Artifact Approval。
- 对中文日志的任何实质性修改必须同步到英文 mirror。
