# Decision Log

Chronological audit trail of substantive human decisions.

## Entry schema

### YYYY-MM-DD — Dxxx

**Source:** Human author / Human acceptance of AI proposal  
**Classification:** `CONTENT` / `FORM` / `PROTOCOL` / multi-label  
**Decision:** ...  
**Affected files/layers:** ...  
**Supersedes:** ... / none  
**Implementation status:** pending / partial / implemented

---

## Rules

- Preserve superseded decisions rather than deleting history.
- Do not log every casual sentence; log durable project-relevant state.
- If a decision changes the current source of truth, reconcile the relevant core immediately.
- Record framework approvals and final-artifact approvals explicitly.
