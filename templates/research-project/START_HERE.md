# START HERE — HARC Project Zero-Context Onboarding

> **Language:** Chinese canonical: `START_HERE.zh-CN.md`; this English file is the synchronized mirror.

This file is the entry point for any AI Agent taking over this research project from zero context.

## Mandatory first step

Before substantive work:

1. read `HARC_MANIFEST.yaml`;
2. read `AGENTS.zh-CN.md`;
3. follow the manifest required read order;
4. output a HARC Onboarding Report;
5. begin substantive work only after reporting blocking clarifications, framework state, and permitted next action.

## Onboarding Report must include

- protocol version / adopted commit;
- canonical language;
- current human content commitments;
- current Form state;
- current `BLOCKING` clarifications;
- task-relevant `NON-BLOCKING` clarifications;
- Working / Approved Framework state;
- current Artifact state;
- known synchronization defects;
- permitted propagation path for the current request.

## Clarification-first

For high-impact uncertainty about claims, concepts, terminology/translation, scope, inference, or structure, do not guess:

`ambiguity -> Clarification Register -> human resolution -> Decision Log -> Core -> Argument Map -> Artifact`

## Normal decision propagation

`human decision -> Decision Log -> appropriate Core -> Argument Map -> Artifact -> bilingual parity`

## Bilingual governance

Unless the project explicitly decides otherwise, Chinese is canonical and English is the synchronized mirror.
