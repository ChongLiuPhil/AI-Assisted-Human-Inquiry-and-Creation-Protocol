# Ethics and Information Technology — Submission Checklist

**Status:** `ACTIVE — FINAL ARTIFACT APPROVAL PENDING`  
**Official guideline checked:** 2026-09-21  
**Official page:** https://link.springer.com/journal/10676/submission-guidelines

## Manuscript form

- [x] Target category treated as Original Research Paper / conceptual-methodological original research.
- [x] Blinded manuscript prepared separately from canonical project article.
- [x] Approximate content length is within 5,000–8,000 words under repository counting.
- [x] Abstract is 150–250 words.
- [x] Keywords count is 4–6.
- [x] No more than three displayed heading levels.
- [x] References use author–year presentation.
- [x] Submission derivative reference list removes uncited internal evidence-only references.
- [x] Reproducible Word/docx build pipeline added to CI.
- [ ] CI-generated Word/docx build candidate visually checked page by page.
- [ ] Page numbering / plain-font Word formatting checked in final docx.

## Double-anonymous review

- [x] Author names removed from blinded manuscript.
- [x] Affiliations and contact details absent from blinded manuscript.
- [x] Internal AHICP Decision IDs, Framework IDs, development status, and Working Memory IDs removed.
- [x] Direct GitHub URL absent from blinded manuscript.
- [x] Masked reviewer derivative prepared with `AHICP`, full protocol name, direct GitHub URL, and internal IDs removed.
- [ ] Human/editorial confirmation of the masked reviewer route completed; residual search-based deanonymization risk explicitly accepted or further mitigated.
- [ ] Any supplementary/repository material supplied to reviewers is anonymized or provided through an appropriate masked route.
- [ ] Self-citations checked for wording that could disclose identity.

## AI / LLM disclosure

- [x] Substantive generative-AI use is disclosed in the manuscript.
- [x] Disclosure distinguishes generative drafting/restructuring from copy editing.
- [x] No AI system is listed as an author.
- [x] Human accountability for final claims, sources, citations, and manuscript is explicit.
- [ ] Exact model/tool names, versions where available, and material dates verified against project records if the final journal/editorial process requests them.

## Research data and declarations

- [x] Data Availability Statement included.
- [x] Statement accurately says no original empirical dataset or completed empirical experiment is reported.
- [ ] Competing Interests statement completed by the human author in the current submission interface.
- [ ] Funding statement completed by the human author.
- [ ] Author Contribution information completed by the human author if required.
- [ ] Acknowledgements finalized outside the blinded manuscript.
- [ ] ORCID / corresponding-author metadata completed if applicable.

## Scholarly final review

- [ ] Latest-head CI confirms the explicit 18-entry citation ↔ reference-list bidirectional mapping for both traceable and masked manuscripts.
- [x] Reference-list entries checked for publication/acceptance status and core metadata; see `CITATION_AUDIT.md`.
- [x] Major DOI / proceedings / standards identifiers checked; dynamic policy URLs remain subject to pre-submission recheck.
- [ ] English language and argument flow reviewed at artifact level.
- [ ] Claim boundaries checked against `MA-FW-001`.
- [ ] No empirical-effectiveness claim introduced.
- [ ] No venue adaptation has changed a core Framework thesis.
- [ ] Final Artifact Approval recorded.
- [ ] Submission authorization recorded separately.

## Submission integrity

- [ ] Human confirms the manuscript is not simultaneously under consideration elsewhere.
- [ ] Human confirms all author/co-author approvals required for submission.
- [ ] Human verifies the live journal interface immediately before submission because submission fields may differ from static guidelines.
